# OrionServer

Custom Minecraft Bedrock server software built as an **MMORPG-oriented engine**: fixed-map workloads, regionized multithreading, and a plugin SDK for game-specific systems.

OrionServer is **not** a generic vanilla Bedrock Dedicated Server clone. The public core stays minimal and region-safe; MMORPG features (combat, kingdoms, NPC routines, and similar) live in separate plugins.

## Status

Early development. Expect breaking API changes.

## Requirements

- .NET 10
- Linux x64 recommended for production
